# 튜터 업무대시보드

사우고등학교 디지털튜터의 하루 업무를 한 화면에서 기록·관리하는 웹 대시보드입니다. 설치 없이 브라우저에서 바로 열립니다.

## 바로 사용하기

👉 **[튜터 업무대시보드 열기](https://hiation33-arch.github.io/sau-tutor-dashboard/)**

## 주요 기능

| 메뉴 | 하는 일 |
|---|---|
| 오늘 | 오늘 기록, 처리 대기 고장, 수업 지원, 기기 상태, 월별 업무 주기 |
| 빠른 접수 | 메신저로 받은 요청을 붙여 넣으면 고장 접수·수업 지원·계정 처리로 자동 분류 |
| 고장·수리 | 접수 → 진단 → AS 의뢰 → 완료 칸반 (끌어서 이동) |
| 수업 지원 | 주간 시간표(1~7교시), 시간 겹침 표시 |
| 기기 현황 | 학급별 상태, 충전함 점검, 관리대장(엑셀 붙여넣기·복사) |
| 일지·보고 | 일일 활동일지와 월간 실적 보고서 자동 작성 → 한글 문서에 붙여넣기 |

## 처음 사용할 때

1. 처음 열면 둘러보기용 **예시 데이터**가 보입니다.
2. 상단 노란 안내의 **[예시 지우고 시작]** 을 누릅니다.
3. 우측 상단 ⚙ **설정**에서 학교 이름, 작성자, 학급·장소 목록을 우리 학교에 맞게 고칩니다.
4. **기기 현황 → 관리대장 → 엑셀에서 붙여넣기**로 기기 목록을 등록합니다.

## 주의사항

- 기록은 **사용하는 브라우저(localStorage)에만 저장**되며 서버로 전송되지 않습니다. 다른 컴퓨터·브라우저와는 공유되지 않습니다.
- 브라우저 방문 기록·사이트 데이터를 지우면 기록도 사라집니다. 설정의 **[백업 코드 복사]** 로 주기적으로 백업해 주세요.
- 메신저 내용을 붙여 넣을 때는 학생 이름을 지우고 번호만 남기세요.
- 이 저장소에는 예시 데이터만 들어 있습니다. 실제 업무 기록은 올라가지 않습니다.
